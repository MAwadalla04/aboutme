## Priority Issues

### [P1] Mandatory 7.6s Intro Animation Blocks Time-Constrained Reviewers
- **Why it matters**: Senior engineering managers and recruiters spend 15–30 seconds total per candidate portfolio. Forcing an unskippable 7.6s animation risks immediate bounce before credentials are seen.
- **Fix**: Add a visible "Skip intro [ESC]" control in the corner of `.intro-overlay`, and dismiss the intro immediately upon any keypress or click.
- **Suggested command**: `$impeccable polish src/components/Hero.js`

### [P1] Navigation Relies on Full Browser Document Reloads
- **Why it matters**: Header navigation links (`/about`, `/experience`, `/projects`) use raw anchor clicks, tearing down React state, triggering server roundtrips, and flashing white between pages.
- **Fix**: Intercept internal route navigation with `history.pushState` and lightweight client-side state transitions in `App.js` and `Header.js`.
- **Suggested command**: `$impeccable polish src/components/Header.js`

### [P2] Semantic Numbering Collision Between Routes and Sections
- **Why it matters**: On `/about`, sections are numbered `01 / About`, `02 / Currently Reading`, and `03 / Contact`. Concurrently, the primary navigation defines `02 / Experience` and `03 / Projects`. This creates conflicting mental models of what "02" and "03" represent.
- **Fix**: Reserve two-digit primary numbering (`01`, `02`, `03`) exclusively for routes, and use clear editorial sub-kickers or plain titles for in-page subsections.
- **Suggested command**: `$impeccable layout src/App.js`

### [P2] Three Out of Four Project Captures Disabled in Data
- **Why it matters**: In `src/data/projects.js`, `image` properties for LegalDocuMan, Autograd, and NYCEM DLS remain commented out, showing abstract SVG schematics while only KnicksIQ has real interface evidence.
- **Fix**: Enable the existing image assets in `public/images/projects/` to back up all four projects with tangible visual proof.
- **Suggested command**: `$impeccable polish src/components/VisualIndex.js`

### [P3] Banned Eyebrow Kickers and Misleading Loading Caption
- **Why it matters**: Banned `.about-kicker` labels (`01 —`) clutter `About.js` headings, while the autograd caption "loading / forward pass" confuses mathematical demonstration with network lag.
- **Fix**: Remove the eyebrow spans in `About.js` and rename the caption in `Hero.js` to `calculating / forward pass`.
- **Suggested command**: `$impeccable clarify src/components/About.js`
